## The Pain Point: How to Display AI Agent UI?

With the explosion of LLMs and AI Agents, an increasing number of apps are integrating Agent capabilities. But this comes with a frustrating problem: **How should the client render the dynamic UI interfaces generated by the Agent?**

A common compromise is **WebView + HTML**. While this approach is cross-platform, the experience is often infuriating:
- ❌ Loss of smooth, native scrolling gestures.
- ❌ Inability to perfectly adapt to iOS Dark Mode and Dynamic Type.
- ❌ Severe performance degradation and memory footprint.
- ❌ Difficult to deeply integrate with native host app components (like MapKit or Swift Charts).

To solve Server-Driven UI (SDUI) issues, Google proposed the [A2UI Protocol](https://github.com/google/A2UI) (Agent to UI), which uses an expressive JSON schema to describe UI architecture. However, the Apple ecosystem has always lacked a robust, native A2UI renderer.

This is why I developed [A2UI-SwiftUI](https://github.com/BBC6BAE9/a2ui-swiftui).

## 🎉 A2UI-SwiftUI: True Native Apple Rendering

**A2UI-SwiftUI** is an open-source SwiftUI native renderer, designed specifically to parse and render the A2UI protocol. **No WebViews, no cross-platform bridging—just 100% pure native SwiftUI components.**

Currently, the project is **featured on Google A2UI's [Official Ecosystem Page](https://a2ui.org/ecosystem/renderers/)**!

### Core Highlights

🌟 **Across All Platforms**  
One codebase perfectly adapts to **iOS 17+, macOS 14+, visionOS 1+, watchOS 10+, and tvOS 17+**. Your Agent can not only run on a phone but can be directly rendered in native 3D spatial environments on Apple Vision Pro!

⚡️ **Silky Smooth Performance & Native Experience**  
When the Agent asks you to render an input box, the SDK invokes `SwiftUI.TextField`. A date picker leverages a native `DatePicker`. This means:
- Zero WebView initialization overhead.
- Perfect support for Accessibility, Dynamic Type, and Dark Mode.
- Seamless integration with the Apple design language.

🔄 **Property-Level Two-Way Binding via `@Observable`**  
Written with the latest Observation framework to achieve efficient selective re-rendering. Input typed by the user or values adjusted on a slider are bound in real-time, allowing the Agent to fetch the latest state seamlessly.

📡 **Streaming Rendering**  
You no longer need to wait for huge chunks of JSON to finish generating. Enjoy JSONL streaming support—**as the Agent streams data out, the UI smoothly renders it**, drastically reducing user wait anxiety on the initial render.

🧩 **Easily Extendable Custom Components**  
The project has **18 standard protocol components** built-in, from `Text` and `Button` to `Tabs` and `Modal`. Need more? You can effortlessly inject your custom native charts or maps:

```swift
A2UISurfaceView(viewModel: vm)
    // Register custom components located in the host app
    .environment(\.a2uiCustomComponentRenderer) { typeName, props, viewModel in
        if typeName == "MySwiftChart" {
            AnyView(MyChartView(props: props))
        } else {
            nil
        }
    }
```
