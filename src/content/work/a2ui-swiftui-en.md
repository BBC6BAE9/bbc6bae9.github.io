Developed and maintained **A2UI-SwiftUI**, a fully native AI Agent UI rendering library for all Apple platforms (iOS, macOS, visionOS).

- Replaced traditional WebView + HTML compromises with 100% pure native SwiftUI components.
- Seamlessly integrates with Apple's design principles (Accessibility, Dynamic Type, Dark Mode).
- Built on the modern Observation framework for real-time two-way bindings and JSONL streaming.
- Officially recognized and featured on the Google A2UI Ecosystem showcase page for renderers.
